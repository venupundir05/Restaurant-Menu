# Restaurant Menu Card

A simple and responsive restaurant menu website built using HTML and CSS. The project displays different food categories, menu items, prices, and restaurant details in a clean and user-friendly layout.

## Features

- Restaurant header with name and tagline
- Categorized menu sections
  - Starters
  - Main Course
  - Desserts
  - Beverages
- Food item cards with price and description
- Responsive design
- Footer with contact information

## Technologies Used

- HTML5
- CSS3

## Project Structure

 Restaurant- Menu
  - inde.html
  - style.css
